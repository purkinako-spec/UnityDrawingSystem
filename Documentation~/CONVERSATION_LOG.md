## 記録 2: 採点システムの評価基準に関する質疑
- **ユーザー質問**:
  - 「採点の評価基準を教えて」
- **回答**:
  - システム内に存在する4種類のスコアラー（`PixelSimilarityScorer`, `ShapeScorer`, `StructuralScorer`, `CompositeScorer`）の仕組み、計算式、向いている用途を解説。

## 記録 3: 「見本が画面全体、ユーザー描画が右下」の場合の評価挙動
- **ユーザー質問**:
  - 「例えば参考画像はキャンバスいっぱいに書いてあって、ユーザが書いたのは右下に書いた場合はどのように採点される？」
- **回答**:
  - 従来のスコアラーは「絶対座標」で比較するため、位置・サイズがずれていると点数はほぼ 0 点（低スコア）になる仕様であることを説明。
  - どこに・どんなサイズで描いても形さえ合っていれば加点する「位置・スケール不変（Translation & Scale Invariant）」のアプローチを提示。

---

## 記録 4: 微小点・ゴミ描画によるバウンディングボックスの破綻リスク
- **ユーザー指摘**:
  - 「それだと外側に点が見えないレベルで書いてあったら基準が大きくなって点数低くならない？」
- **回答 & 評価**:
  - 指摘の通り、単純な最小・最大座標による矩形判定だと、端の1ドットのゴミでキャンバス全体に枠が広がり破綻する。
  - これを防ぐため「微小連結成分（孤立クラスタ）のノイズ除去」「外れ値パーセンタイル除外」を組み合わせるのが最善策であることを説明。

## 記録 6: 採点精度の厳格化と難易度（Difficulty）の float 調整
- **ユーザー要望**:
  - 「めっちゃ適当でも80点簡単にとれちゃう」
  - 「ちゃんと採点されるようにだけして。あと難易度調整をfloatでできるようにして」
- **対応内容**:
  - 白背景/透明背景の自動判別機能を追加し、背景を「描画」と誤認する不具合を根本解消。
  - 判定を Precision（見本に対する余計な線の罰則）と Recall（見本に対する線の充足率）に基づく F1-score + IoU に刷新。適当な殴り書きでは点数が出ないよう厳密化。
  - `Difficulty`（0.0f〜1.0f）の float パラメータを導入。難易度スライダーで判定の厳しさをリアルタイムに調整可能にした。

## 記録 7: ビルド後のインゲーム操作対応・レイヤー操作・カラーピッカー・終了ボタン
- **ユーザー要望**:
  - 「ビルドしたら描けない」
  - 「レイヤーの操作が全然できない。バグってる。全体を見直して」
  - 「inspectorで操作できるもののほぼすべてを操作できるようにして」
  - 「色をもっと自由に変更できるようにして」
  - 「ゲーム終了のボタンを配置して」
- **根本原因の分析と特定**:
  1. **ビルドで描けない問題**:
     - `CanvasScaler` が `ConstantPixelSize` (800x600基準) だったため、Standalone の解像度によって描画 RawImage のサイズがマイナスや極小になり、UV変換の除算ガード（`rect.width <= 0`）で描画が弾かれていた。
     - 操作パネルのクリックが入力を横取りしていた、または UI 操作時と描画キャンバスの境界判定が不完全だった。
     - New Input System と Legacy Input のフォールバック処理で Standalone 実行時のマウス・ペン入力が不安定になっていた。
  2. **レイヤー操作ができない問題**:
     - レイヤーの追加・削除ボタンしかなく、レイヤー一覧・選択・表示/非表示（👁）・上下移動・不透明度・ブレンドモードの制御 UI が未実装だった。
- **対応内容**:
  - **`RuntimeControlPanel.cs` の完全刷新**:
    - スクロールビュー（`ScrollRect`）対応により、縦長パネルがはみ出さず全機能にアクセス可能。
    - **レイヤー完全操作**: レイヤー一覧表示、選択中レイヤーのハイライト、表示/非表示切り替え、追加・削除、上下並び替え、不透明度スライダー、4種のブレンドモード（Normal / Multiply / Screen / Overlay）選択。
    - **無段階HSVカラーピッカー**: プリセットパレットに加え、Hue（色相）・Saturation（彩度）・Value（明度）の各スライダーとHEXコード表示を実装し、どんな色でも自由に作成可能に。
    - **キャンバス背景色切り替え**: 白・紙色・グレー・ダーク・黒から即時変更可能。
    - **採点コントロール**: 難易度（Difficulty）スライダー、常時自動採点トグル＆間隔調整、即時採点ボタン。
    - **ゲーム終了ボタン**: アプリ終了ボタン（`Application.Quit` / エディタ停止）を赤色で配置。
    - **常時表示の開閉トグルボタン**: キーボードのない環境でもペン/マウスのワンタップでパネル開閉が可能（Tabキー開閉も併用）。
  - **`DrawingCanvas.cs` & `InputProvider.cs` の堅牢化**:
    - `EventSystem.RaycastAll` による非干渉UIブロッキング判定を導入。パネル操作中に誤って線が引かれるのを完全に遮断。
    - New Input System と Legacy Input のハイブリッドフォールバックを実装し、ビルド環境でもペン・マウス問わず確実に描画可能に。
    - シーンの `CanvasScaler` を `ScaleWithScreenSize (1920x1080)` に更新し、どんな画面解像度でもキャンバスが消滅・縮小しないよう修正。
